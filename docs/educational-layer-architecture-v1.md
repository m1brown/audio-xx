# Audio XX — The Educational Layer
## Editorial architecture (design v1 — no UI change)

Status: **editorial-architecture design.** No components built, no layout changed.
Governing boundary: primary sources only — manufacturer documentation, designer statements, patents, manuals — never third-party reviews ([[artifact_v1_evidence_and_visual_direction]], D-7 epistemic fidelity).

---

### 0. The principle

Education is **a stratum woven through the assessment, not a section bolted on.** When the reader finishes, they should understand not only *their system* but the **philosophies, designers, lineages, countries, and technical ideas** it embodies — and *why those philosophies reinforce or oppose one another.* It stays quiet: a clause, a keyed reference, a scaled diagram — never a review, never an encyclopedia entry, never a paragraph of biography in the reading flow.

The mechanism: the educational layer is **provenance + philosophy attached to blocks the assessment already has.** It rides the Subject, the Engineering section, the Dominant Character, and the reference layer. Nothing new appears; the existing blocks simply carry one more, licensed, quiet dimension.

---

### 1. Where educational moments naturally belong

| Existing block | Educational moment it naturally carries | Register |
|---|---|---|
| **Subject / component strip** | One **origin clause** per component: *designer · country/tradition · the one idea it embodies.* | A single clause under each name. |
| **Recognition** | The **tradition** the builder's intent descends from (light touch). | Half a sentence, only when it clarifies. |
| **Engineering** | The **heart of the layer** — name the *design philosophies* each component embodies, and show **how they reinforce or oppose.** | Woven into the existing mechanism prose. |
| **Tonal Signature** | The axes *are* the philosophies made visible — the chart teaches by showing where each school pulls. | No words added; the diagram already teaches. |
| **Dominant Character** | The **synthesis** — the distilled resolution of the competing philosophies. | Already one sentence; unchanged in form. |
| **Reference layer** (margin / expand) | The **deep material**: designer statements, patents, manuals, model lineage, country/tradition history, **manufacturer resource links.** | Keyed, quiet, out of the reading flow. |

The intellectual payoff — *why philosophies reinforce or oppose* — lives in **Engineering**, because that section already explains why the components cohere. Education is not a new question there; it is the same question answered one level deeper.

---

### 2. Always-present vs. progressive

**Always present** (in the reading flow, one clause each):
- each component's **origin clause** (designer · country · one idea);
- in Engineering, the **names of the philosophies** and their **reinforce/oppose** relationship;
- a country/tradition mention **only where it materially shapes the sound.**

**Progressive** (revealed on interaction; lives in the reference layer, never the main flow):
- designer biography and full **designer statements**;
- **patents, manuals, white papers** (the primary-source trail);
- **model history / lineage** and the house's evolution;
- deeper technical explanation of a named idea;
- **manufacturer resource links.**

Rule of thumb: the reading flow carries *what a claim is*; the reference layer carries *the primary source that licenses it and the depth for the curious.* A reader who never expands anything still gets a complete, quietly educational assessment.

---

### 3. Manufacturer links without interrupting reading

- Links live **only in the reference layer** — as quiet keyed references (a superscript by the claim, opening a margin note / tap-to-expand aside / a "Primary sources" list). **Never an inline hyperlink in the prose.**
- Each link is **typed by evidence class** (manufacturer page · manual · designer interview · patent · technical note) so the reader sees what kind of source it is before following it.
- Links are **commercial-free**: manufacturer/official/primary destinations only; retailer/affiliate links remain quarantined and out of scope.
- The reading experience is unbroken: the prose is complete on its own; the keys are an invitation, not a dependency.

---

### 4. Teaching philosophy throughout, not in one place

Distribute the teaching along the arc so no single "philosophy" block ever forms:

1. **Introduce** each component's philosophy where the component is first named (Subject / early Engineering) — one idea, one clause.
2. **Interact** — the Engineering section shows the philosophies *meeting*: which reinforce (same direction) and which oppose (pull against each other), and how the system resolves the tension.
3. **Visualise** — the Tonal Signature is the philosophies plotted; a reader learns the schools by seeing where each component pulls on the axes.
4. **Synthesise** — the Dominant Character is the one-line resolution of the competing philosophies.

The lesson is cumulative and structural: by the end, the reader has been taught the schools *by watching them resolve into their own system's character* — the most durable way to teach, and the reason the artifact is worth keeping.
